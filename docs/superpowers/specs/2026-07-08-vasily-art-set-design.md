## 1. Контекст и зачем

Текущие 19 котов уровней кликера (`cat-stage1..19.png`) — визуально разные коты
(ChatGPT-генерации разных сессий) с хамстер-комбатовской лестницей «спорт → деньги
→ власть». Пользователь отверг прогрессию РАЗМЕРОМ кота (введена и откачена
08.07: «слишком огромная разница») и решил: прогрессия должна читаться через
**одежду, украшения и фон**, кот — **всегда один и тот же, одного размера**.

Решения брейншторма:

1. **Базис — канонический Василий** (единый IP бренда: мультсериал cartoon-studio,
   «Кофейня Василия», бенто-промо, «Дом кота»). Референс:
   `C:/Users/user/cartoon-studio/assets/refs/kotik/kotik_ref_01_front.png` —
   пухлый рыжий кот, полосатый мех, кремовая грудка, зелёные глаза, розовый
   ошейник с кулоном «М». **Кулон «М» — константа всех образов.**
2. **Тематика лестницы — кондитерская карьера** (от стажёра до Императора выпечки),
   названия уровней меняются под образы.
3. **Фон на каждый уровень (19 фонов)** — отдельным слоем сцены (как сейчас
   `.ck-scene`), кот-вырез поверх.
4. **Скоуп: только кликер.** «Дом кота» (позы + шляпы) — фаза 2 тем же каноном,
   отдельная спека после приёмки кликер-комплекта.
5. **Генерация — Flow / Nano Banana** (выбор пользователя; Higgsfield NBP —
   запасной). Гео-грабля: Flow блокирует РФ → US-VPN + перезапуск flow-auto
   Chrome уже за VPN.
6. Прогрессия размером в кликере удалена (`7d3da83`, v95) — кот всегда крупный;
   это состояние сохраняется.

## 3. Генерация (Flow / Nano Banana)

- **Профиль:** playwright MCP под `flow-auto` ([[reference_flow_automation]]).
  ⚠️ Гео: US-VPN обязателен; если flow-auto держит старые прямые соединения —
  убить chrome.exe процессы flow-auto, MCP переоткроет за VPN.
- **Консистентность персонажа:** референс `kotik_ref_01_front.png` прикладывается
  к первой генерации; далее контекст диалога держит персонажа (приём голубей-иконок:
  референс один раз, дальше «тот же кот»). Единый style-block дословно в каждом
  промте (наработки `cartoon-studio/PROMPT-METHOD.md`).
- **Промт-анатомия образа:** [кот-референс + константы (кулон «М», поза стоя
  анфас-¾, добрая улыбка)] + [одежда/аксессуар уровня] + [чистый белый фон для
  выреза] + [style-block] + «still IMAGE (not video)».
- **QC-правила (юзер, 08.07):** у кота РОВНО 4 лапы, не больше; кулон — ТОЛЬКО
  бело-красный логотип «М» (силуэт девушки, как на референсе) на розовом
  ошейнике; НИКАКИХ букв на груди/одежде и надписей на фоне. Нарушители — в
  реген. Известные реген-кандидаты батча B: шоколатье (надпись «Chocolatie» +
  «М» на груди), юный кондитер («М» на груди).
- **Фоны:** отдельные генерации без кота: [сцена уровня] + [перспектива «сцена за
  персонажем», нижняя треть свободна под кота] + [палитра тёплая, бренд «Марии»]
  + style-block. Вертикальная композиция под мобильный экран.
- **Батчи:** до 4 кадров за промт; брак перегенерируется точечно.
- **Скачивание:** canvas → `toDataURL` → base64-файл (shell-curl слеп за VPN) либо
  `media.getMediaUrlRedirect` — приёмы из памяти Flow-сессий.

## 4. Пост-обработка (скрипты имеются/дорабатываются)

1. **Вырезка фона кота:** flood-fill от краёв + эрозия (пайплайн 19-котов) +
   обязательный прогон **детектором шахматки** (скользящее окно, классы белый
   250+/серый 237–249 — сессия 08.07) — замкнутые карманы вычищаются сразу.
2. **Нормализация:** trim по альфе → единый РОСТ КОНТЕНТА (не холста!) → единый
   нижний якорь → единая ширина холста. Это гарантирует «кот одного размера»
   между уровнями без рантайм-масштабирования.
3. **Форматы:** коты — PNG (прозрачность, ~440px ширина как сейчас), фоны — webp
   q80 (~50–80КБ, размер под мобильный вьюпорт, как `scene/tier*.webp`).
4. **Контактные листы** на каждый батч (монтаж на тёмном+светлом фоне) — для
   ревью пользователем и самопроверки детектором.

## 5. Интеграция в код (фронт-онли + зеркало имён)

- **Ассеты:** `public/assets/images/cat/vasily-stage1..19.png` (коты),
  `public/assets/images/scene/career1..19.webp` (фоны). Старые `cat-stage*` и
  `scene/tier*` остаются в репо до полной приёмки (мгновенный откат).
- **`catclick.js`:** `LEAGUES[].cat` → новые файлы; `LEAGUES[].name` → новые
  названия; слой `.ck-scene`/`bgTier` переводится с 6 тиров на пер-уровневый фон
  (`data-tier` → номер уровня 1..19, маппинг 1:1).
- **`clicker.ts` (бэк):** зеркало `LEAGUES` — меняются только `name` (поля `cat`
  на бэке нет), **пороги `need` НЕ меняются** — прогресс игроков сохраняется.
- Кэш-бастеры `catclick.js?v=`, при необходимости `?v=` на картинки (`BIZ_ART_V`-паттерн).
- Механика, экономика, вехи, задания — не трогаются.

## 6. Этапы и приёмка

1. **Пилот:** 3 образа (ур. 1, 11, 19) + 1 фон (ур. 11) → обработка → контактный
   лист пользователю. Гейт: пользователь одобряет стиль/консистентность.
   Без одобрения массовая генерация не начинается.
2. **Массовая генерация:** остальные 16 образов + 18 фонов батчами, точечные
   перегенерации брака, контактные листы.
3. **Интеграция и деплой:** нормализация, замена ассетов и имён, локальная
   визуальная проверка (гость, превью-сервер), деплой на VPS, прод-проверка.

## 7. Риски

- **Гео-блок Flow** — US-VPN, перезапуск flow-auto за VPN (известная грабля).
- **Дрейф персонажа между батчами** — референс + style-block + точечные
  перегенерации; финальный контактный лист всех 19 бок о бок.
- **Похожесть соседних образов** (ур. 2 vs 3, 10 vs 11) — различающий аксессуар
  прописан в промте каждого уровня; проверяется на контактном листе.
- **Объём:** 38 изображений + обработка ≈ 1–2 рабочие сессии; квоты Flow Pro —
  стилы дешевле видео, но следить.
- **Названия уровней** уходят в прод для существующих игроков — смена нейминга
  безопасна (пороги те же), но заметна; это осознанное решение ребрендинга.
