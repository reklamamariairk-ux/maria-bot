# Обучение новичка: интерактивный тур Василия

**Дата:** 2026-07-31 · **Запрос юзера:** «проработаем детально обучение когда новый юзер
только входит в игру — что за что отвечает, что нужно делать, как пользоваться».

## Что было

Welcome-карточка (3 тезиса + «Поехали!»), разрозненные коуч-тултипы по триггерам,
статичный «Полный гайд», FTUE-чеклист «Первый день». Связной проводки «сделай то → смотри
сюда» не было; коучи наслаивались на попапы.

## Что становится

**Интерактивный тур с Василием-проводником** (11 шагов, ~90 секунд): спотлайт-подсветка
элемента (дырка в затемнении) + пузырь Василия с мордочкой + «Дальше»/«Пропустить».
Два шага ждут РЕАЛЬНОЕ действие игрока (авто-переход без кнопки):

1. Привет от Василия (кот в спотлайте)
2. «Тапни меня 5 раз» — ждёт 5 тапов (счётчик в onTap)
3. Энергия: тап стоит 1, сама восстанавливается
4. Баланс и доход/час
5. «Открой „Прокачку“» — ждёт перехода на вкладку (хук setTab)
6. Карточка «Пекарни»: 300 монет → +30/час, первый бизнес
7-10. Тур по табам одной строкой каждому: Голуби / Призы / Дом / Рейтинг
11. Финал: передача эстафеты чеклисту «Первый день» (спотлайт на чип)

## Механика

- Спотлайт: маленький див над целью (pointer-events:none) с box-shadow 0 0 0 9999px
  затемнения — клики проходят к цели (нужно для шагов-действий).
- Пузырь позиционируется над/под целью с клампом в вьюпорт; z-index ниже ck-pop.
- Коучи подавлены на время тура (guard в coach()), чтобы не наслаивались.
- Прогресс: `ck_tour_v1` в localStorage ('done'). Запуск: после «Поехали!» welcome-карты;
  страховка — при open(), если welcome видел, тур не проходил и игрок свежий (taps < 30).
  Работает и для гостя (обучение до входа — важный кейс веб/VK).
- «Пропустить» всегда доступен (мелкой кнопкой), помечает done.
- В «Полный гайд» добавляется пункт «Пройти обучение заново» (сброс + старт).

## Не делаем

Принудительную блокировку остального UI (мягкий тур: ушёл в сторону — тур ждёт на своём
шаге), выдачу монет в туре (стартовый капитал уже даёт FTUE-чеклист).
