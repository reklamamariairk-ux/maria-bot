# Котик Комбат — отдельное приложение без магазина (game.html)

**Дата:** 2026-07-13
**Статус:** одобрено юзером (дизайн-диалог), ждёт implementation-плана

## Задача

Сделать «Котик Комбат» отдельным приложением: игрок открывает Mini App @mariatortik_bot и попадает сразу в игру — магазин не грузится и не появляется вообще. Магазин временно недоступен из Telegram; позже его «внедрим внутрь» игрового приложения (отдельный будущий проект, здесь не проектируется).

## Принятые решения (диалог 13.07.2026)

| Вопрос | Решение |
|---|---|
| Форма | Отдельная страница-вход `game.html`; бот остаётся **@mariatortik_bot** (новый бот НЕ создаём — потом внутрь этого приложения внедрим магазин) |
| Прогресс | Общий с текущей игрой (тот же бот → тот же chat_id → та же `clicker_state`; получается автоматически) |
| Коммерция в игре | **Чистая игра**: welcome-промо, «До подарка», задания про заказы, витрина наград — скрыты (режим `ck-pure`) |
| Магазин | **Временно спрятать совсем**: диплинки из старых пушей начнут открывать игру; откат — вернуть URL в BotFather |
| VK | Не трогаем: VK-версия продолжает открывать полный `index.html` с магазином |
| Пуши | Шоп-пуши (статус заказа, ДР и т.д.) не выключаем — уходят текстом, ссылки из них теперь открывают игру |
| Ретеншн-пуши игры | Остаются как есть (шлются этим же ботом) |

## Архитектура

**Бэкенд не меняется.** Тот же BOT_TOKEN, та же валидация initData (`src/auth.ts`), те же API `/api/clicker*`. Ноль миграций БД.

**Новая страница `public/game.html`** — самостоятельный вход:

- Тёмный сплеш («Котик Комбат загружается…», как текущий `#ck-splash`).
- Грузит ТОЛЬКО игровое: `tg-bridge.js`, `catclick.js`, `catpet.js` и их стили/ассеты (точный минимальный список скриптов определяется в implementation-плане по фактическим зависимостям игры). НЕ грузит `app.js`, каталог, корзину, клубные экраны.
- Ставит на `<html>` классы `ck-gamefirst` (авто-открытие игры) и **новый `ck-pure`** (чистый режим).
- Кнопка закрытия игры в pure-режиме закрывает Mini App (`App.close()` через бридж); в браузере-госте кнопка скрыта. «Выходить в магазин» больше некуда.
- Гостевой режим в браузере работает (localStorage), как сейчас — путь для e2e-тестов.

**Ручной шаг юзера (после деплоя):** в BotFather `@mariatortik_bot → Bot Settings → Configure Mini App → Edit Main Mini App URL` → `https://bot.145-223-121-47.sslip.io/game.html`; то же для кнопки меню, если она настроена отдельно. Настройка живёт только в BotFather, через API не меняется.

## Чистый режим `ck-pure`

Флаг читается в `catclick.js`/`catpet.js` (html-класс). Скрывает/отключает коммерцию:

- welcome-промокод (карточка MARIA10 + вызовы `/api/clicker/welcome*`);
- виджет «До подарка» (`#pet-gift`) и клейм вех заботы с реальными баллами;
- задания-маркетинг с коммерцией (отзыв, заказы, подписки);
- витрину реальных наград (обмен монет; и так за флагом, но UI-вход скрыть);
- упоминания «баллы на карту "Марии"» в туториале и попапах (тексты в pure-варианте — про игру);
- обмен `bonus300` (вход в UI).

Игровое ядро остаётся целиком: тапалка, 19 уровней и сцены, бизнесы, бусты, daily combo + шифр, стрик, сундук, золотой дождь, хаб мини-игр, Дом кота (без призового виджета), сквады, лидерборд, рефералы (`?start=ckref_` уже ведёт в @mariatortik_bot — правок не требует).

Серверные эндпоинты коммерции не трогаем: UI скрыт → обращений нет. Точный список точек ветвления — задача implementation-плана.

## Последствия, принятые осознанно

- Диплинки из уже отправленных пушей (`startapp=rate_`, `wish_`, корзина) открывают игру, а не магазин. Приемлемо, временно.
- Прямой URL `https://bot.145-223-121-47.sslip.io/` (index.html) продолжает отдавать магазин (нужен VK); из Telegram на него больше ничего не ведёт.
- Откат всей фичи = вернуть Main Mini App URL на старый в BotFather (мгновенно, без деплоя).

## Тестирование

1. **E2e гостем** (локальный статик или stage): `game.html` открывается сразу в игру; ни одного коммерс-блока (welcome, «До подарка», витрина наград, коммерс-задания); консоль без ошибок; тап/уровни/бизнесы работают.
2. **Регресс index.html**: магазин и игра в нём работают как раньше (в т.ч. VK-смоук `scripts/vk_port_smoke.js`).
3. **Смоук в Telegram** после смены URL в BotFather: открытие, авторизация (прогресс подхватился серверный), закрытие крестиком сворачивает Mini App.

## Вне скоупа

- Внедрение магазина внутрь игрового приложения (будущий проект).
- VK-версия игры без магазина.
- Пуши/ретеншн от имени отдельного бота (бот не меняется).
- Любые правки серверной логики наград/лояльности.
