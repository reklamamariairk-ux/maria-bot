# Драг-заезд v2: механика «Идеальный запуск»

**Дата:** 2026-07-30 · **Причина:** решение юзера «нужно всё-таки другую механику драг-рейсинга».
Предыстория: одиночный тап-на-реакцию оказался ловушкой (тап до «СТАРТ!» молча игнорировался →
записывалась худшая реакция 3000мс, прокачанный голубь стабильно последний, см. memo 30.07 №4)
и слишком мелкой механикой — одно касание на весь заезд, дальше кино.

## Игровая петля (клиент)

Запуск драгстера как в настоящем драг-рейсинге — три осмысленных инпута ДО старта,
резолв и анимация не меняются (server-authoritative сохранён):

1. **Прогрев** — шкала-тахометр, стрелка ходит пинг-понгом (полный свип ~1.4с),
   золотая зона у красной черты. Тап — фиксируем отступ от центра зоны (мс).
2. **Форсаж** — та же шкала, стрелка быстрее (~1.0с) — второй тап.
3. **Сцепление** — ёлка 3-2-1-зелёный, тап на зелёный = реакция (как раньше), но:
   - тап на красных → мгновенный фидбек **«Рано! Жди зелёный»** (вибро + вспышка),
     не штрафуем и не игнорируем молча — лечим главную ловушку v1;
   - не тапнул за 2 свипа/3с → худший результат этапа, едем дальше (как v1).
4. После каждого инпута — оценка: «Идеально!» (≥0.9) / «Хорошо!» (≥0.6) / «Рано»/«Поздно».
5. Результат: к месту и ставке добавляется брейкдаун запуска
   («Прогрев 92% · Форсаж 71% · Старт 0.28с») — игрок видит, ЧТО улучшать.

## Сервер (src/drag.ts)

Payload v2: `skill: { rev1: offsetMs, rev2: offsetMs, reactionMs }` — всё untrusted, клампы на сервере.

- `revAccuracy(off) = clamp01(1 − |off|/REV_HALF)`, REV_HALF = 300мс.
- `reactAccuracy(ms) = clamp01(1 − (clampReact(ms) − REACT_MIN)/REACT_SPAN)`, REACT_SPAN = 600
  (200мс → 1.0; ≥800мс → 0).
- `launchSkill = 0.3·rev1 + 0.3·rev2 + 0.4·react` ∈ [0,1] — реакция чуть главнее (это драг).
- `dragFinishTimeV2(power, skill, r) = TRACK_LEN/(BASE+5·power) + (1−skill)·SKILL_SPREAD + r·LUCK_V2`.
- Соперники: мощность/подбор/гард как v1 (bet: слабее target−10 → бот ≈target);
  **skill соперников раздаёт сервер**: bet U[COMP_SKILL_LO, COMP_SKILL_HI], training U[0.35, 0.90].
- Константы SKILL_SPREAD/LUCK_V2/COMP_SKILL_* подбираются ТОЛЬКО Монте-Карло в
  `tests/drag.test.ts` (паттерн EV-фикса 30.07):
  - идеальный скрипт (skill=1.0) — EV ≤ 0 (казна не кормит читера);
  - честный хороший запуск (~0.8) — EV в −5..−35% ставки;
  - навык значим: EV(0.85) − EV(0.4) > 0.3 ставки;
  - при равной мощности выше skill → раньше финиш (без люка).
- **Обратная совместимость:** body без `skill` (кэшированные клиенты catdrag v4) → старый
  путь v1 целиком (dragFinishTime + hardenBetField по реакциям). Удалим после раскатки.
- `race_reaction_ms` пишем из `skill.reactionMs` — легаси-тренировки продолжают жить.
- Ответ + `mySkill: {rev1, rev2, react, total}` для брейкдауна в результате.

## Что НЕ меняем

Анимация заезда, подиум, ставки/выплаты (PAYOUT), энергия, транзакционная модель,
недельная «Гонка стаи», тюнинг. Клиент по-прежнему не доверенный: меняется только
ЧТО он честно измеряет (3 отступа вместо 1 реакции).
