# Assets для UI

## Hero video (опционально)

Положить файл по пути:
- `/public/assets/hero.mp4` — основной (H.264, 1080p/720p, MP4)
- `/public/assets/hero.webm` — опционально для размера на Chrome (VP9, можно опустить)

**Параметры:**
- Длина: 8-12 секунд (петля)
- Разрешение: 1080×1920 (vertical, 9:16) или 1080×1350 (4:5) — оба норм
- Размер файла: до 5 MB после оптимизации
- Без звука (всё равно `muted`)

**Сюжет:** руки кондитера украшают торт; капля шоколада; вид сверху на готовый десерт; первый кусок. Что-то медитативное.

**Как оптимизировать:**
```
ffmpeg -i input.mov -c:v libx264 -crf 28 -preset slow -pix_fmt yuv420p -an -vf "scale=-2:1080" hero.mp4
```

Если файла нет — hero сохраняет статичную фотографию (текущее поведение).

## Onboarding photos (опционально)

Папка `/public/assets/onboarding/` — full-bleed фото для cinematic onboarding:
- `1992.jpg` — архивное фото кухни Марии (sepia tone)
- `2008.jpg` — первое кафе на Ленина (classic/muted)
- `2026.jpg` — современное фото производства (warm/now)

**Параметры:**
- Aspect ratio: 9:16 (vertical, как сторис)
- Разрешение: 1080×1920 рекомендую
- Формат: JPG, размер до 500 KB на фото

Если файлов нет — Onboarding покажет градиентные фолбэки в стиле sepia/classic/red.
