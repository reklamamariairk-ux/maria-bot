# Интеграции на стороне сайта maria-irk.ru

## partners.php — синхронизация партнёров клуба

Эндпоинт для отдачи партнёров клуба «Мария для своих» из админки Bitrix
(Site Manager) в JSON. Mini-app дёргает его раз в час и обновляет список
без редеплоя.

### Шаг 1 — создать инфоблок в админке Bitrix

Админка → **Контент → Информационные блоки → Информационные блоки** →
**Добавить информационный блок**.

- Название: `Партнёры клуба`
- Символьный код: `partners_club` (важно — этот код прописан в `partners.php`)
- Тип: любой (например, «Контент»)

В **«Свойства»** добавить:

| Код | Тип | Назначение |
|---|---|---|
| `ICON_EMOJI` | Строка | Эмодзи-логотип, например 🔬 |
| `PERK` | Строка | Текст бейджа: «−35%», «🎁 Ролл», «−1 450 ₽» |
| `DESCRIPTION_FULL` | HTML/текст | Описание привилегии (несколько строк) |
| `CATEGORY` | Список (опционально) | Здоровье / Красота / Рестораны / Отдых / Дети / Подарки |

В **«Доступ»** разрешить чтение группе `Все пользователи (в т.ч. неавторизованные)` —
эндпоинт защищён собственным токеном, но Bitrix-права тоже должны позволять чтение.

### Шаг 2 — заполнить элементы

Каждый партнёр = один элемент инфоблока. Активные (`ACTIVE = Y`) попадают в выдачу.

### Шаг 3 — залить `partners.php` на сервер

Положить файл в `/local/api/partners.php` (создать папки, если нет):

```
/home/bitrix/www/local/api/partners.php
```

В файле **обязательно поменять** константу `PARTNERS_TOKEN` на длинную случайную строку.
Сохранить эту строку — она же пойдёт в env-переменную `PARTNERS_TOKEN` на Render.

Проверить:

```
curl "https://www.maria-irk.ru/local/api/partners.php?token=YOUR_TOKEN"
```

Должен вернуть JSON с массивом `partners`.

### Шаг 4 — прописать env на Render

В Render Dashboard у сервиса `maria-bot`:

```
PARTNERS_API   = https://www.maria-irk.ru/local/api/partners.php
PARTNERS_TOKEN = тот_же_токен_что_в_partners_php
```

После рестарта в логах будет:

```
[STARTUP] Partners cron scheduled (hourly)
[PARTNERS] synced N from Bitrix
```

Mini App автоматически начнёт показывать актуальный список.

### Без эндпоинта

Если `PARTNERS_API` не задан — бот отдаёт партнёров из `data/partners.json`
(бандлится с репозиторием). Это fallback для старта без админки.

## lk.php — Личный кабинет с сайта

Эндпоинт для получения баланса бонусов / уровня клуба / билетов «Сладкого
чека» по номеру телефона. Бот вызывает после того, как юзер подтвердил
номер через Telegram-контакт — повторной SMS-верификации не нужно.

### Шаг 1 — настроить файл

Открой `infrastructure/lk.php`:

1. **`PARTNERS_TOKEN`** → длинная случайная строка (отдельная от
   токена партнёров). Сохранить — пойдёт в env Render как `LK_TOKEN`.
2. **`ALLOWED_IPS`** *(опционально)* → массив IP-адресов сервера Render,
   откуда разрешены запросы. Если оставить пустым `[]` — разрешены все
   (защищает только токен).
3. В коде есть **2 секции, которые нужно подогнать под реальную структуру
   вашей системы лояльности** (помечено комментарием `ВАЖНО: ниже —
   заглушка`):
   - **Поиск пользователя по телефону** — сейчас пробует `PERSONAL_PHONE`
     и `PERSONAL_MOBILE`. Если у вас телефон в другом поле (например,
     `UF_PHONE`) — добавить.
   - **Получение баланса/уровня** — сейчас читает `UF_BONUS_BALANCE`,
     `UF_YEAR_SPENT`, `UF_LOYALTY_LEVEL` пользовательских полей b_user.
     Если бонусы лежат в другом модуле (Sale, отдельный инфоблок) —
     заменить на реальное чтение. Должен возвращать `int`.
   - **Билеты «Сладкого чека»** — пример читает инфоблок
     `sweet_check_tickets`. Если такого нет — удалить блок или
     указать свой код.

### Шаг 2 — залить файл

Положить в `/local/api/lk.php` (рядом с `partners.php`):

```
/home/bitrix/www/local/api/lk.php
```

Проверить:

```
curl "https://www.maria-irk.ru/local/api/lk.php?token=YOUR_LK_TOKEN&phone=79991234567"
```

Должен вернуть JSON: `{"found": false}` для незнакомого номера или
`{"found": true, "name": "...", "level": "...", "balance": 1234, ...}`
для зарегистрированного.

### Шаг 3 — env на Render

```
LK_API   = https://www.maria-irk.ru/local/api/lk.php
LK_TOKEN = тот_же_токен_что_в_lk_php_(PARTNERS_TOKEN)
```

После рестарта в Mini App во вкладке «Клуб» появится секция
**«Мой счёт на сайте»** с балансом и билетами. До этого секция скрыта.

### Безопасность

- Токен передаётся в URL → не логируйте URL запросов целиком в access-log
  (или экранируйте `?token=`).
- Если хотите параноидально — добавьте IP-whitelist в `ALLOWED_IPS`.
  IP сервера Render можно посмотреть в логах их CDN-провайдера или
  спросить у поддержки.
- Бот вызывает эндпоинт **только** для номеров, верифицированных через
  Telegram-контакт (поле `phone_verified_at IS NOT NULL` в `subscribers`).
